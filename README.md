# 📱 PhonePe Digital Payments Analysis

## 📌 Project Overview

This project analyzes PhonePe digital payment data across different
states and districts in India.

The analysis focuses on transaction trends, user behavior, device
usage, transaction types, district demographics, and relationships
between demographic and digital payment data.

The project was developed using Python and Jupyter Notebook and
includes data exploration, data quality checks, exploratory data
analysis, data merging, visualization, and business insights.

## 🎯 Business Objective

The objective of this project is to analyze digital payment activity
across states and districts and identify meaningful patterns in:

- Transaction volume and transaction amount
- Transaction types
- Registered users
- Device brand usage
- App usage
- District population and population density
- Relationship between demographic data and transaction activity

The project also compares state-level and district-level data to
identify potential data discrepancies.


## ❓ Business Questions

The analysis answers questions such as:

1. How do transaction volumes vary across states and years?
2. Which states have the highest and lowest transaction volumes?
3. What are the most common transaction types across states and
   quarters?
4. Which device brands have the highest number of registered users?
5. Which districts have the highest population in each state?
6. What is the average transaction value across states?
7. How does app usage change over time?
8. Is there a relationship between population density and transaction
   volume?
9. Are state-level and district-level transaction data consistent?
10. Which states have the highest average transaction amount per user?

## 🔍 Analysis Performed

### 1. Data Loading & Understanding

- Loaded multiple PhonePe datasets
- Examined dataset structure
- Checked data types
- Generated summary statistics
- Identified missing values
- Calculated state and district counts

### 2. Exploratory Data Analysis

- Analyzed transaction trends over time
- Identified top and bottom states by transaction volume
- Analyzed transaction types
- Analyzed device brand usage
- Identified highest-population districts
- Calculated Average Transaction Value (ATV)
- Analyzed app usage trends

### 3. Data Quality Checks

- Compared state-level and district-level transaction data
- Compared transaction amounts and registered users
- Identified discrepancies between datasets

### 4. Advanced Analysis

- Calculated registered users to population ratio
- Analyzed population density vs transaction volume
- Calculated average transaction amount per user
- Analyzed device brand usage ratio

### 5. Data Visualization

The project includes:

- Line charts
- Bar charts
- Pie charts
- Scatter plots
- Population and demographic visualizations


## 📊 Key Insights

The analysis identified several important patterns in digital payment
activity across India.

Some of the key findings include:

- Karnataka, Maharashtra and Telangana were among the highest
  transaction-volume states in the analysis.
- Transaction activity varied significantly across states and time
  periods.
- Device brand usage differed across states.
- Population and digital payment activity were analyzed to understand
  demographic relationships.
- State-level and district-level datasets showed discrepancies that
  were investigated as part of the data quality analysis.
- Average transaction amount per registered user varied across states.

Detailed findings, tables and visualizations are available in the
Jupyter Notebook.
